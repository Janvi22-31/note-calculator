About Note Calculator

What this project is and how it's built

Note Calculator is a simple full-stack web application that calculates the number of currency notes required for a given amount and denomination. For example, if you enter ₹5000 and choose the ₹500 note, it tells you that you need 10 notes, with ₹0 left over.

Technology Stack

Frontend

HTML, CSS, JavaScript

Backend

Java, Spring Boot

Database

MySQL

Communication

REST API

How it works

The frontend sends the amount and denomination to the Spring Boot backend using a REST API call. The backend calculates the number of notes and remaining amount, saves the result in a MySQL database, and sends the result back as JSON, which the frontend then displays.
